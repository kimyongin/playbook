# 업무에 쓰는 앱 만들기 가이드

이 저장소는 개발 경험이 없는 사람이 개발 에이전트와 함께 실제 업무에 쓸 앱을 만드는 과정을 스킬로 정리합니다. 참여자는 업무와 원하는 결과를 설명하고, 에이전트는 개발 방식 설명부터 설계·구현·검증까지 진행합니다. 현재 제공하는 스킬은 **데모 1**입니다.

## 데모 1에서 만드는 것

팀원이 각자의 계정으로 접속할 수 있는 업무 서비스를 만듭니다. 사람은 웹 화면을 직접 조작하거나 에이전트에게 자연어로 요청합니다. 에이전트는 MCP로 같은 업무 데이터와 규칙을 사용합니다. 사용자 로그인·데이터 저장·접근 권한에는 Supabase를 활용합니다. 업무 자료는 직접 입력, 외부 API, 웹 수집 중 필요한 방법으로 확보합니다.

데모는 다음 활동을 프로젝트 상황에 맞춰 진행합니다.

1. 실제 업무 사례를 듣고 첫 기능을 정합니다. 개인 자동화와 공동 서비스 등 가능한 개발 방법도 비교합니다.
2. 웹·에이전트·서버·데이터베이스·외부 서비스가 주고받는 정보를 HTML 흐름도로 보여주고, 업무 규칙과 권한을 확인합니다.
3. 에이전트가 필요한 로컬 개발 도구를 확인·설치하고, 첫 기능을 웹과 MCP에 연결합니다.
4. 기능 변경 때 중복되거나 더 이상 쓰지 않는 부분을 정리하고, 배포 후 다른 계정과 실제 에이전트에서도 동작을 확인합니다.

## 시작하기

[데모 1 스킬](.codex/skills/demo-1-build-work-app/SKILL.md)을 지정하고 자신의 업무를 설명하세요. 예를 들어 다음처럼 요청할 수 있습니다.

> `$demo-1-build-work-app`을 사용해 우리 팀의 요청 관리 업무를 앱으로 만들고 싶어. 개발은 처음이니 최근 업무 사례를 물어보고, 데이터가 어떻게 이동하는지 그림으로 보여줘.

에이전트는 이미 설치된 도구와 진행 상태부터 확인합니다. 사용자가 직접 해야 하는 계정 로그인이나 컴퓨터 승인 화면이 나오면 그때 필요한 행동을 안내합니다. 업무에 사용할 실제 데이터와 공개 범위는 사용자와 확인합니다.
